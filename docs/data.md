# Reference Datasets & Zenodo Repositories

Pre-computed distribution sets, motif lists, model profiles, and consensus sequences trained on 1,019 long-read sequencing samples from the 1000 Genomes Project are publicly available on Zenodo.

## Zenodo Releases

| Version | Download Link | Description |
| --- | --- | --- |
| **Version 0.5** | [Zenodo Dataset v0.5](https://zenodo.org/records/18786409) | Latest distribution catalogues and model parameters. |
| **Version 0.2** | [Zenodo Dataset v0.2](https://zenodo.org/records/14967709) | Version 0.2 datasets and feature matrices. |
| **Version 0.1** | [Zenodo Dataset v0.1](https://zenodo.org/records/14629433) | Initial release data tables. |

## Data Files Overview

- **`consensus_sequences_complete.fa`**: FASTA consensus sequences for Alu, LINE-1, and SVA mobile elements.
- **`source_loci_LINE1.tsv` & `source_loci_SVA.tsv`**: Genomic loci tables for transductions.
- **`Separated_Motifs.tsv` & `SVA_VNTR_Motifs.txt`**: Motifs for tandem repeat sampling.
- **`ERRHMM-ONT-HQ.model`**: Error model file for Oxford Nanopore read simulation in Module 5.
